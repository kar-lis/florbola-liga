# florbola-liga

## apraksts
Python un Flask tīmekļa lietotne florbola līgu rezultātu reģistrācijai,  turnīra tabulas un spēlētāju statistikas apskatei.

## Tehnoloģijas
- Python 3
- Flask
- SQLite
- Jinja2 (HTML šabloni)
- werkzeug.security (paroļu šifrēšana)
